智能指针 - 现代 C++ 内存管理

概述

智能指针是现代 C++ 内存管理的核心工具，它通过 RAII 机制自动管理动态分配的内存，避免了内存泄漏和悬垂指针问题。C++11 引入了三种智能指针：std::unique_ptr、std::shared_ptr 和 std::weak_ptr。

本章将深入探讨：

  • 智能指针的类型和特点
  • 每种智能指针的使用场景
  • 智能指针的性能考虑
  • 智能指针的最佳实践

核心概念

三种智能指针

  1. std::unique_ptr：独占所有权，轻量级，不可拷贝
  2. std::shared_ptr：共享所有权，引用计数，可拷贝
  3. std::weak_ptr：弱引用，不增加引用计数，解决循环引用

智能指针的优势

  • 自动内存管理，避免内存泄漏
  • 异常安全
  • 明确的所有权语义
  • 防止悬垂指针

最佳实践

使用建议

  1. 优先使用 make_unique 和 make_shared

  2. 默认使用 unique_ptr

  3. 避免循环引用

  4. 不要混用裸指针和智能指针

常见陷阱

  • shared_ptr 循环引用

  • 使用裸指针初始化多个 shared_ptr

  • this 指针与 shared_ptr
