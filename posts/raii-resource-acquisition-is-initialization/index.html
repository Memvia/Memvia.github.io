RAII - 资源获取即初始化

概述

RAII（Resource Acquisition Is Initialization，资源获取即初始化）是 C++ 中最重要的资源管理惯用法。它的核心思想是将资源的生命周期与对象的生命周期绑定，利用 C++ 的析构函数机制自动释放资源。

RAII 的优势：

  • 自动资源释放，避免内存泄漏
  • 异常安全：即使抛出异常也能正确释放资源
  • 代码简洁，减少手动管理的错误
  • 保证资源的确定性释放

核心概念

RAII 的基本原理

  1. 构造函数获取资源
  2. 析构函数释放资源
  3. 利用栈对象的自动销毁机制

RAII 的典型应用场景

  • 内存管理（new/delete）
  • 文件句柄
  • 网络连接
  • 互斥锁
  • 数据库连接
  • GUI 资源

使用建议

  1. 优先使用标准库的 RAII 类型

  2. 遵循三法则/五法则

  3. 使用 std::lock_guard 管理互斥锁

  4. 异常安全保证

常见陷阱

  • 返回裸指针

  • 异常构造函数中的资源泄漏

  • 循环引用导致 shared_ptr 无法释放
