容器 - STL 容器全面指南

概述

C++ STL 容器是标准模板库中最重要和最常用的组件之一。容器提供了存储和管理对象的高效数据结构，每种容器都有其特定的性能特征和适用场景。选择合适的容器对于编写高效、可维护的 C++ 代码至关重要。

本章将深入探讨：

  • 序列容器
  • 关联容器
  • 无序容器
  • 容器适配器
  • 容器的性能考虑
  • 容器的最佳实践

核心概念

容器分类

序列容器：维护元素的插入顺序

  • std::vector：动态数组
  • std::deque：双端队列
  • std::list：双向链表
  • std::forward_list：单向链表

关联容器：基于键排序

  • std::set/std::multiset：集合
  • std::map/std::multimap：映射

无序容器：基于哈希表

  • std::unordered_set/std::unordered_multiset：无序集合
  • std::unordered_map/std::unordered_multimap：无序映射

容器适配器：提供特定接口

  • std::stack：栈
  • std::queue：队列
  • std::priority_queue：优先队列

迭代器分类

  • 输入迭代器：只读，单向
  • 输出迭代器：只写，单向
  • 前向迭代器：读写，单向
  • 双向迭代器：读写，双向
  • 随机访问迭代器：读写，随机访问

最佳实践

使用建议

  1. 默认使用 vector

  2. 需要频繁在中间插入删除时使用 list

  3. 需要快速查找时使用关联容器或无序容器

  4. 使用 emplace 避免不必要的拷贝
